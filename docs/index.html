Features

Small, reliable, and actually private

Everything WebMemX does happens locally in your browser — nothing here talks to a server.

Local-first privacy

Everything lives in chrome.storage.local. No backend, no cloud database, no accounts, no analytics services.

Unique URL tracking

Smart normalization dedupes same-day visits without blindly stripping query parameters that identify distinct pages.

History rescan

Backfills missed activity straight from Chrome's own history, with an incremental cache so repeat scans are fast.

Domain analytics

Today's unique URLs rolled up by origin, so you can see which sites your browsing actually came from.

Dashboard popup

Stat counts, a 7-day trend chart, top domains, and today's activity — all in one clean popup.

Light / dark / auto

Follows your OS by default, or pin a theme explicitly — same toggle pattern used across the extension.

How it works

From navigation to dashboard

A minimal, event-driven pipeline — no polling, no continuously running scripts.

01

Navigate

chrome.webNavigation detects a real page load in the main frame.

02

Normalize

Scheme/host lowercased, fragment dropped, trailing slash trimmed. Query params kept.

03

Dedupe per day

Each normalized URL counts once per local calendar day, stored independently.

04

Display

The popup renders live stats, trend, and domain breakdown straight from local storage.

Get started

Install as an unpacked extension

Not on the Chrome Web Store yet — loading it takes about a minute.

  1. Clone the repo
  2. Open chrome://extensions
  3. Enable Developer mode
  4. Click Load unpacked, select the folder
  5. Open the toolbar icon — today backfills automatically
$ git clone https://github.com/srsuiux/WebMemX.git $ cd WebMemX # load unpacked in chrome://extensions
Trust

Only the permissions it needs

No host permissions — WebMemX never reads page content, only navigation URLs.

PermissionWhy
storagePersist daily activity locally in chrome.storage.local.
webNavigationDetect page navigations as they happen.
historyRescan and backfill activity from your existing browser history.
